# नेपाल कानून तथा संविधान १०-स्तम्भ डेटा पोर्टल (Nepal Legal & Constitution Data Portal)

github.com/barshapbp2026/any-pdf- रिपोजिटरीमा रहेका सम्पूर्ण कानूनी कागजातहरू (संविधान, ऐन, नियमावली, निर्देशिका, कार्यविधि र अनुसूचीहरू) लाई व्यवस्थित रूपमा १०-स्तम्भ डेटा ढाँचामा सङ्कलन, प्रमाणीकरण र प्रस्तुत गर्ने वेब अनुप्रयोग।

---

## 📂 प्रणालीका मुख्य विशेषताहरू (Core Features)

1. **१०-स्तम्भ मास्टर तालिका संरचना (10-Column Master Schema):**
   - **१. Folder ID:** फोल्डरको क्रमबद्ध सङ्ख्या (१ देखि १२ सम्म सेरियल्ली)।
   - **२. Subfolder ID:** सबफोल्डरको सङ्ख्या (नभएमा खाली `-`)।
   - **३. Folder Name:** मूल फोल्डरको नाम (नेपालको संविधान, ऐन, नियमावली आदि)।
   - **४. Subfolder Name:** सबफोल्डरको नाम।
   - **५. PDF Name:** मूल PDF कागजातको स्पष्ट फाइल नाम (क्लिक गरेर सिधै खोल्न मिल्ने)।
   - **६. ID (धारा/दफा/नियम/निर्देशन/बुँदा ID):** कानुनी प्रावधानको नम्बर।
   - **७. Title Name (५ उप-स्तम्भहरू):**
     - **७.१ धारा (Dhara):** संविधानका धाराहरूका लागि।
     - **७.२ दफा (Dafa):** ऐन तथा गठन आदेशका दफाहरूका लागि।
     - **७.३ नियम (Niyam):** नियमावलीका नियमहरूका लागि।
     - **७.४ निर्देशन (Nirdeshan):** निर्देशिकाका निर्देशहरूका लागि।
     - **७.५ बुँदा (Bunda):** कार्यविधि तथा मापदण्डका बुँदाहरूका लागि।
   - **८. Title Page:** मूल PDF मा उक्त दफा/धारा रहेको पृष्ठ नम्बर (क्लिक गरेर सिधै PDF भ्युअरमा खुल्छ)।
   - **९. अनुसूची ID:** अनुसूची नम्बर (जस्तै: अनुसूची-१)।
   - **१०. अनुसूची Title:** अनुसूचीको पूर्ण शीर्षक।
   - **११. अनुसूची Print Page:** अनुसूची रहेको मूल PDF पृष्ठ नम्बर।

2. **विशेषताहरू:**
   - **स्मार्ट सेल मर्ज (Row Merge via `rowSpan`):** एउटै फोल्डर र PDF का लगातार पङ्क्तिहरूमा Folder, Subfolder र PDF Name स्वतः मर्ज भई चिटिक्क देखिन्छ।
   - **देवनागरी क्रमबद्धता (Serial Sorting):** फोल्डर र धाराहरूको सेरियल क्रम (१, २, ३ ... १०, ११, १२) मिलाइएको छ।
   - **प्रत्यक्ष PDF भ्युअर (Built-in PDF Viewer Modal):** GitHub Raw स्ट्रिम मार्फत सम्बन्धित पृष्ठमा सिधै जान सकिने सुविधा।
   - **निर्यात (Export):** Excel (`.xlsx`) र CSV (`.csv`) ढाँचामा सबै स्तम्भहरू डाउनलोड गर्न मिल्ने।
